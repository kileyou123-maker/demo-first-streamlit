# ETF X-RAY MVP

ETF X-RAY 是面向投資新手的 ETF 深度研究工具。核心不是提供個人化買賣建議，而是把一般使用者難以自行整理的 ETF 歷史風險、持有體驗與底層曝險做成簡單工具。

## 目前 MVP

- ETF 搜尋與資料庫介面
- 單檔 ETF X-RAY 頁
- 最大回撤 / 恢復時間 / Rolling Return 介面
- ETF 持股重疊比較
- 定期定額情境模擬
- 教育型投資風險問卷
- 點數解鎖流程：預設 5 點體驗額度
- NT$59 / 99 / 199 點數方案 UI
- 手機版介面
- 合規提示與 DEMO DATA 標示

## 資料狀態

目前是產品與分析流程 MVP。數值使用示範資料驗證 UI / 計算流程，不應作為投資決策依據。

正式資料接入原則：

1. 僅使用具合法使用權限、官方開放或已授權的資料來源。
2. 每個分析標示來源、資料日期與計算方法。
3. 優先支援全台灣 ETF 與美國 ETF，再擴充其他市場。
4. 價格報酬、含息總報酬、匯率、費用、配息分開計算與揭露。

## 合規邊界

第一階段不提供：

- 個人化 ETF 推薦
- 買賣比例
- 進出場價
- 明牌或獲利保證
- 根據問卷自動指定特定 ETF

問卷只提供投資教育與風險特徵；付費內容是資料、研究工具與歷史統計。

正式收費前需完成台灣證券 / 投顧法規與金流流程審查。
